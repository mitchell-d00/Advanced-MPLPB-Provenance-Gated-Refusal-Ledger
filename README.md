A closed-corpus, provenance-gated retrieval and refusal ledger combining MPLPB, MitchellTech calculations, and Pendulums conservation checks. Preserves one-owner rules, evidence requirements, and explicit refusals. Includes repaired 56/56 historical retrieval, adversarial tests, reproducible evaluations, and a browser-local interface.
